# openTalk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a macOS menu-bar push-to-talk dictation app: hold a global hotkey, speak, release — on-device Whisper transcript pastes at the cursor via clipboard + synthetic ⌘V, with prior clipboard restored ~200 ms later.

**Architecture:** Single-target Swift app, LSUIElement (no Dock icon). NSStatusItem for the menu bar. `KeyboardShortcuts` library hands us key-down/key-up callbacks; key-down starts AVAudioEngine capture into a 16 kHz mono Float32 buffer, key-up stops capture and feeds the buffer to `WhisperKit.transcribe(audioArray:)`. Result is written to `NSPasteboard.general` (after snapshotting the prior contents); we synthesise a Cmd+V `CGEvent` pair, then restore the snapshot 200 ms later. SMAppService.mainApp handles login launching. Settings live in UserDefaults, surfaced through a small SwiftUI Settings scene. Project is generated by XcodeGen so the `.xcodeproj` stays out of git.

**Tech Stack:** Swift 5.9+, SwiftUI + AppKit, macOS 14+, Apple Silicon only (`ARCHS = arm64`), XcodeGen, [argmaxinc/WhisperKit](https://github.com/argmaxinc/WhisperKit), [sindresorhus/KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts), AVFoundation, ServiceManagement (SMAppService), CoreGraphics (CGEvent), ApplicationServices (AXIsProcessTrustedWithOptions).

import Foundation
import Observation

@Observable
final class SettingsStore {
    private let defaults: UserDefaults

    init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
        // Set defaults if absent.
        if defaults.object(forKey: Keys.selectedModel) == nil {
            defaults.set("openai_whisper-base.en", forKey: Keys.selectedModel)
        }
        if defaults.object(forKey: Keys.restoreDelay) == nil {
            defaults.set(200, forKey: Keys.restoreDelay)
        }
    }

    var selectedModelName: String {
        get { defaults.string(forKey: Keys.selectedModel) ?? "openai_whisper-base.en" }
        set { defaults.set(newValue, forKey: Keys.selectedModel) }
    }

    var clipboardRestoreDelayMs: Int {
        get { defaults.integer(forKey: Keys.restoreDelay) }
        set {
            let clamped = min(2_000, max(100, newValue))
            defaults.set(clamped, forKey: Keys.restoreDelay)
        }
    }

    private enum Keys {
        static let selectedModel = "openTalk.selectedModelName"
        static let restoreDelay = "openTalk.clipboardRestoreDelayMs"
    }
}
```

final class AudioBufferConverterTests: XCTestCase {
    func test_downsample_48kStereo_to_16kMono_halvesAndAverages() throws {
        // 1 second of 48kHz stereo: left = 1.0, right = -1.0 → mono should be 0.0
        let inFormat = AVAudioFormat(commonFormat: .pcmFormatFloat32,
                                     sampleRate: 48_000,
                                     channels: 2,
                                     interleaved: false)!
        let frames: AVAudioFrameCount = 48_000
        let buf = AVAudioPCMBuffer(pcmFormat: inFormat, frameCapacity: frames)!
        buf.frameLength = frames
        for i in 0..<Int(frames) {
            buf.floatChannelData![0][i] = 1.0
            buf.floatChannelData![1][i] = -1.0
        }
        let converter = try AudioBufferConverter(inputFormat: inFormat)
        let out = try converter.append(buf).flush()
        XCTAssertEqual(out.count, 16_000, accuracy: 50)            // ~1s @ 16k
        XCTAssertLessThan(abs(out.reduce(0, +) / Float(out.count)), 0.01)
    }
}

import AVFoundation

enum AudioRecorderError: Error {
    case engineFailed(Error)
    case converterFailed(Error)
}

@MainActor
final class AudioRecorder {
    private let engine = AVAudioEngine()
    private var converter: AudioBufferConverter?
    private var collected: [Float] = []
    private var isRunning = false

    func start() throws {
        guard !isRunning else { return }
        collected.removeAll(keepingCapacity: true)

        let input = engine.inputNode
        let inFormat = input.outputFormat(forBus: 0)
        let conv = try AudioBufferConverter(inputFormat: inFormat)
        self.converter = conv

        input.installTap(onBus: 0, bufferSize: 4_096, format: inFormat) { [weak self] buffer, _ in
            guard let self else { return }
            do {
                let chunk = try conv.append(buffer)
                Task { @MainActor in self.collected.append(contentsOf: chunk.flushPending()) }
            } catch {
                // Drop chunk on conversion failure; surface in stop().
            }
        }

        engine.prepare()
        do { try engine.start() } catch { throw AudioRecorderError.engineFailed(error) }
        isRunning = true
    }

    func stop() -> [Float] {
        guard isRunning else { return [] }
        isRunning = false
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        let tail = (try? converter?.flush()) ?? []
        let result = collected + tail
        collected.removeAll(keepingCapacity: true)
        converter = nil
        return result
    }
}

// MARK: - AudioBufferConverter

/// Streams arbitrary-format input AVAudioPCMBuffers and yields 16 kHz mono Float32 samples.
final class AudioBufferConverter {
    static let targetSampleRate: Double = 16_000
    static let targetFormat: AVAudioFormat = AVAudioFormat(
        commonFormat: .pcmFormatFloat32,
        sampleRate: AudioBufferConverter.targetSampleRate,
        channels: 1,
        interleaved: false
    )!

    private let converter: AVAudioConverter
    private let outputFrameCapacity: AVAudioFrameCount = 16_384
    private var pending: [Float] = []

    init(inputFormat: AVAudioFormat) throws {
        guard let c = AVAudioConverter(from: inputFormat, to: Self.targetFormat) else {
            throw AudioRecorderError.converterFailed(NSError(domain: "openTalk.AudioBufferConverter", code: 1))
        }
        self.converter = c
    }

    /// Convert a single input buffer; returns the slice produced *during* this call.
    @discardableResult
    func append(_ inBuffer: AVAudioPCMBuffer) throws -> [Float] {
        let outBuffer = AVAudioPCMBuffer(pcmFormat: Self.targetFormat,
                                         frameCapacity: outputFrameCapacity)!
        var consumed = false
        var error: NSError?
        let status = converter.convert(to: outBuffer, error: &error) { _, outStatus in
            if consumed {
                outStatus.pointee = .noDataNow
                return nil
            }
            consumed = true
            outStatus.pointee = .haveData
            return inBuffer
        }
        if status == .error, let error { throw AudioRecorderError.converterFailed(error) }
        let samples = floats(from: outBuffer)
        pending.append(contentsOf: samples)
        return samples
    }

    /// Drain any pending samples (called on stop()).
    func flush() throws -> [Float] {
        let snapshot = pending
        pending.removeAll(keepingCapacity: false)
        return snapshot
    }

    /// Used by `AudioRecorder` to take samples out as they arrive without losing flush data.
    func flushPending() -> [Float] {
        let snapshot = pending
        pending.removeAll(keepingCapacity: true)
        return snapshot
    }

    private func floats(from buffer: AVAudioPCMBuffer) -> [Float] {
        guard let ptr = buffer.floatChannelData?[0] else { return [] }
        return Array(UnsafeBufferPointer(start: ptr, count: Int(buffer.frameLength)))
    }
}
```

> **Note:** the `[Float]` array escapes the audio render thread via `Task { @MainActor in ... }`. This is fine for push-to-talk volumes (typically a few hundred KB per utterance) but if you ever stream long-form, replace with a `DispatchQueue.async` onto a dedicated serial queue that owns `collected`.

import Foundation
import WhisperKit

final class WhisperKitTranscriber: Transcriber, @unchecked Sendable {
    private var pipeline: WhisperKit?
    private(set) var isReady = false

    func load(modelName: String, progress: @Sendable @escaping (Double) -> Void) async throws {
        do {
            let config = WhisperKitConfig(
                model: modelName,
                verbose: false,
                logLevel: .error,
                prewarm: true,
                load: true,
                download: true
            )
            // WhisperKit emits download/load progress via its own Progress; we surface coarse milestones.
            progress(0.05)
            let kit = try await WhisperKit(config)
            progress(1.0)
            self.pipeline = kit
            self.isReady = true
        } catch {
            throw TranscriberError.underlying(error)
        }
    }

    func transcribe(samples: [Float]) async throws -> String {
        guard let pipeline else { throw TranscriberError.notLoaded }
        do {
            let results = try await pipeline.transcribe(audioArray: samples)
            return results.map(\.text).joined(separator: " ")
                .trimmingCharacters(in: .whitespacesAndNewlines)
        } catch {
            throw TranscriberError.underlying(error)
        }
    }
}
```

> **Note on progress:** WhisperKit's `WhisperKit(config)` initialiser does not currently expose a granular progress stream for *both* download and warm-up. The two `progress(...)` calls above are coarse milestones — adequate for an onboarding spinner. If a future WhisperKit version exposes finer progress, replace the two calls with the proper observer.

import AppKit
import ApplicationServices

struct PasteboardSnapshot {
    private let entries: [(NSPasteboard.PasteboardType, Data)]

    static func capture(_ pb: NSPasteboard) -> PasteboardSnapshot {
        let types = pb.types ?? []
        var entries: [(NSPasteboard.PasteboardType, Data)] = []
        for t in types {
            if let d = pb.data(forType: t) { entries.append((t, d)) }
        }
        return PasteboardSnapshot(entries: entries)
    }

    func restore(into pb: NSPasteboard) {
        pb.clearContents()
        for (type, data) in entries {
            pb.setData(data, forType: type)
        }
    }
}

@MainActor
final class Paster {
    private let restoreDelayMs: () -> Int

    init(restoreDelayMs: @escaping () -> Int) {
        self.restoreDelayMs = restoreDelayMs
    }

    /// True iff the running process is allowed to post synthetic key events.
    static func accessibilityTrusted(prompt: Bool = false) -> Bool {
        let key = "AXTrustedCheckOptionPrompt" as CFString
        let opts = [key: prompt] as CFDictionary
        return AXIsProcessTrustedWithOptions(opts)
    }

    /// Paste `text` at the current cursor location, then restore the prior clipboard.
    func paste(_ text: String) {
        guard !text.isEmpty else { return }

        let pb = NSPasteboard.general
        let snapshot = PasteboardSnapshot.capture(pb)

        pb.clearContents()
        pb.setString(text, forType: .string)

        synthesizeCmdV()

        let delay = max(100, restoreDelayMs())
        DispatchQueue.main.asyncAfter(deadline: .now() + .milliseconds(delay)) {
            snapshot.restore(into: pb)
        }
    }

    private func synthesizeCmdV() {
        let src = CGEventSource(stateID: .combinedSessionState)
        let vKey: CGKeyCode = 0x09 // ANSI 'v'
        let down = CGEvent(keyboardEventSource: src, virtualKey: vKey, keyDown: true)
        let up   = CGEvent(keyboardEventSource: src, virtualKey: vKey, keyDown: false)
        down?.flags = .maskCommand
        up?.flags   = .maskCommand
        let tap = CGEventTapLocation.cghidEventTap
        down?.post(tap: tap)
        up?.post(tap: tap)
    }
}
```

> **Why `cghidEventTap` and not `cgSessionEventTap`:** `cghidEventTap` injects at the lowest level, before the active app's own event filters — the most reliable way to land a ⌘V in arbitrary text fields. It's the same path that tools like Raycast and TextExpander use.

                await MainActor.run { paster.paste(text) }
            } catch {
                NSLog("openTalk: transcribe failed: \(error)")
            }
        }
    }

    private func openSettings() {
        NSApp.activate(ignoringOtherApps: true)
    }

import ServiceManagement

@MainActor
enum LaunchAtLogin {
    static var isEnabled: Bool {
        get { SMAppService.mainApp.status == .enabled }
        set {
            do {
                if newValue {
                    if SMAppService.mainApp.status != .enabled { try SMAppService.mainApp.register() }
                } else {
                    if SMAppService.mainApp.status == .enabled { try SMAppService.mainApp.unregister() }
                }
            } catch {
                NSLog("openTalk: launch-at-login toggle failed: \(error)")
            }
        }
    }
}

# openTalk

Push-to-talk on-device dictation for macOS, in your menu bar. Hold ⌥Space (configurable), speak, release. Transcript is pasted at the cursor in any text field via clipboard + synthetic ⌘V; the previous clipboard is restored ~200 ms later.

Transcription runs entirely on-device using [WhisperKit](https://github.com/argmaxinc/WhisperKit) — nothing leaves your Mac.

## Build from source

```bash
brew install xcodegen
git clone <repo-url>
cd openTalk
xcodegen generate
open openTalk.xcodeproj
```

Build & run with ⌘R.

## First launch

You'll be asked to grant three things:

1. **Microphone** — so we can hear you.
2. **Accessibility** — so we can post `⌘V` into whatever app is in front. Open System Settings → Privacy & Security → Accessibility, drag `openTalk.app` into the list, and toggle it on. Quit and relaunch openTalk after granting.
3. **Whisper model** — about 145 MB for `base.en` (the default). Downloaded once into `~/Documents/huggingface/`.

The Setup window walks you through these. Reopen it any time from the menu bar's "Setup…" item.

## Settings

Menu bar → **Settings…**. Customise the hotkey, swap the Whisper model, toggle launch-at-login, or tune the clipboard restore delay (100–2000 ms).

## Requirements

- macOS 14+
- Apple Silicon
- Xcode 15+ to build

## Why isn't openTalk sandboxed?

Synthesising a `⌘V` into another app via `CGEvent.post(tap: .cghidEventTap)` is incompatible with the macOS app sandbox. Like Raycast, TextExpander, and similar utilities, openTalk runs unsandboxed and asks for Accessibility permission instead.
